# StudySesh

A focus dashboard for studying: a study timer, a clock, and a place to jot questions to a study assistant.

**Live:** https://himeshahuja.github.io/study-sesh/

## Development

Built with React, TypeScript, Vite and Tailwind.

```sh
npm install
npm run dev
```

## Deployment

Pushes to `main` build the site and publish it to GitHub Pages (`.github/workflows/deploy.yml`).

Started from [a8hok/React-typescript-tailwind-boilerplate](https://github.com/a8hok/React-typescript-tailwind-boilerplate) (MIT).
